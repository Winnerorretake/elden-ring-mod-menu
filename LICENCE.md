## 🧩 About

**Elden Ring helpers** is a curated list of Elden Ring open-source tools:

- **Overlays** — on-screen helpers, layout notes, stat viewer, map markers
- **Quality-of-Life Helpers** — build planner, item catalog, config notes
- **Research Notes** — boss layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Combat & Build Helpers
- Stat Viewer — review attributes and scaling notes
- Build Planner — organize talismans, ashes, and gear
- Boss Layout Notes — segment study on any encounter
- Playback Notes — review recorded runs for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Item Catalog — browse weapons, armor, ashes of war
- Custom Loadout Notes — organize player builds
- Map Marker Overlay — improved visibility of landmarks

### 🏋️ World & Exploration Layout
- Exploration Notes — segment study across regions
- Fast-Travel Helper — manually review grace points
- Inventory Notes — chain complex loadouts in the planner
